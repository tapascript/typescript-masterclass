# Episode 09 - TypeScript Generics: Mini Projects

In this episode, we will do a couple of mini projects using TypeScript Generics Patterns.

## Lessons Covered

- Why duplicate API & repository logic hurts your codebase
- Project 1: Universal data repository layer blueprint
- Defining distinct data contracts (User vs Product)
- Creating the generic IRepository T interface
- Implementing MemoryRepository T class
- Fixing property errors using generic constraints (extends)
- Testing User and Product repositories in action
- Project 2: Universal dynamic API fetch client
- Structuring a generic ApiClient T class
- Executing type-safe API requests
- Adding optional generic response transformers (T, R)
- Mapping snake_case network responses to clean camelCase models
- Practical assignment: Generic Audit Logger challenge
- GitHub source code & community wrap-up
