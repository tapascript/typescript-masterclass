# Episode 07 - Assignment / Task

## Task 1

Select a DOM input using a type assertion, then implement a safer version using instanceof.

## Task 2

Demonstrate why "42" as number does not convert a string. Then perform the correct runtime conversion.

## Task 3

Create an application configuration type and an object using satisfies. Add an incorrect property and
observe the error.

## Task 4

Treat parsed JSON as unknown and safely narrow it to a User type.

## Bonus

Build a feature-flag configuration using as const + satisfies, then derive useful types from it.
